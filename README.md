# Claude-Repo

My first GitHub repository, created with Claude.

## What is this?

This repo is a hands-on introduction to GitHub — learning what repositories, branches, and pull requests are by actually using them.

## Key concepts learned

- **Repository**: a folder on GitHub that tracks every change to your files
- **Branch**: a safe copy where you can make changes without affecting the main version
- **Pull request**: a way to propose changes before merging them in
